How it works. Art Wire collects headlines from art publications — ARTnews, Hyperallergic, Artnet, The Art Newspaper, Artforum, ArtAsiaPacific, Juxtapoz, Hi-Fructose, StreetArtNews, Brooklyn Street Art, Colossal, Plural, Art Market Mag, Artsy — plus Google News, via RSS (through rss2json). Tap any story to read it inside the app; the full text comes from the feed itself or r.jina.ai. If the full text cannot be fetched, Original (Full, Translated) opens the complete article in Burmese through Google Translate.

Translate is a free direct translation (Google Translate, MyMemory as fallback). AI Translate uses your own Gemini key for higher quality. Save keeps an article under the Saved tab — saved articles are stored only on this device (localStorage) and survive app updates.

Gemini API key (optional — for AI Translate). The same key as the PDF-OCR app. Stored only on this device; sent only to Google when translating.

rss2json API key (optional) — if "No news right now" appears often, a free key from rss2json.com raises the limit. Stored only on this device.

r.jina.ai API key (optional) — if the full text often fails to load, a free key from jina.ai improves fetching. Stored only on this device.
